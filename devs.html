UMA BASE EM EVOLUÇÃO

Arquitetura do bot

O projeto combina JavaScript em módulos ESM com TypeScript em partes da base. Os plugins concentram os comandos, enquanto bibliotecas compartilhadas cuidam de tarefas comuns.

O código do bot é privado. Esta página documenta a stack, sem distribuir sessões, configurações operacionais ou credenciais.

AS PEÇAS DO SISTEMA

Tecnologias utilizadas

01 / EXECUÇÃO

Node.js + ESM

Runtime JavaScript com módulos nativos. TypeScript complementa a verificação de tipos na evolução da base.

02 / CONEXÃO

zapo-js

Biblioteca de conexão do bot, acompanhada de utilitários de mídia, componentes nativos e armazenamento SQLite.

03 / MÍDIA

FFmpeg, Sharp & Canvas

Conversão de áudio e vídeo, tratamento de imagens e composição visual de menus e perfis com @napi-rs/canvas.

04 / PERSISTÊNCIA

SQLite & PostgreSQL

Persistência local com better-sqlite3 e integração com Supabase/PostgreSQL em partes do sistema, além de arquivos de dados.

05 / INTEGRAÇÕES

APIs & serviços

Axios, youtubei.js e Alyka API fazem parte das ferramentas e integrações utilizadas pelo projeto.

06 / QUALIDADE

Testes & validação

Node Test Runner, servidor falso da zapo, testes de retenção e verificação incremental com TypeScript, ESLint e Prettier.

A stack descreve a base consultada em 26 de outubro de 2026. Recursos e dependências podem evoluir.
