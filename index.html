DÚVIDAS FREQUENTES

Alguma dúvida?

Ler os termos de uso ↗
Como colocar a Yoshikawa no meu grupo?+

Acompanhe o canal oficial e consulte as opções de aluguel pelo comando !loja em um grupo onde o bot esteja disponível. Se precisar de orientação, entre em contato com o suporte.

Todos os comandos estão disponíveis para todos?+

Não. Alguns comandos dependem de permissões, benefícios ativos ou configurações do grupo. O bot informa as condições ao utilizar cada recurso.

A Yoshikawa é um produto oficial do WhatsApp?+

Não. É um projeto independente, sem vínculo com WhatsApp ou Meta. A disponibilidade depende de serviços externos.

Posso acessar o código-fonte do bot?+

O bot é de código fechado. A página para desenvolvedores apresenta a stack e os créditos, e o GitHub reúne os projetos públicos do desenvolvedor.

Onde acompanho novidades ou peço ajuda?+

Os avisos estão no canal oficial. Para suporte, escreva para yoshikawa.softwares@proton.me ou use !report no bot.
