Como colocar a Yoshikawa no meu grupo?+

Acompanhe o canal oficial e consulte as opções de aluguel pelo comando !loja em um grupo onde o bot esteja disponível. Se precisar de orientação, entre em contato com o suporte.

Todos os comandos estão disponíveis para todos?+

Não. Alguns comandos dependem de permissões de administrador, dono ou desenvolvedor, de um benefício ativo ou da configuração do grupo. O bot informa as condições ao utilizar cada recurso.

A Yoshikawa é um produto oficial do WhatsApp?+

Não. É um projeto independente, sem vínculo com WhatsApp ou Meta. A disponibilidade depende de serviços externos e não há garantia contra interrupções ou restrições da plataforma.

Posso acessar o código-fonte do bot?+

O bot é de código fechado. A página para desenvolvedores apresenta a stack e os créditos; o perfil no GitHub reúne os projetos públicos do desenvolvedor.

Onde acompanho novidades ou peço ajuda?+

Os avisos estão no canal oficial do WhatsApp. Para suporte, escreva para yoshikawa.softwares@proton.me. No bot, use !report para informar um erro.
