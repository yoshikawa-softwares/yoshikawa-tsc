Privacidade

Entenda a diferença entre visitar este site e interagir com o bot no WhatsApp.

Atualizado em 29 de outubro de 2026
01 / NESTE SITE

Dados neste site

Este site é informativo. Não oferece cadastro, não solicita login no WhatsApp e não inclui ferramentas próprias de publicidade ou análise de audiência. O código do site não cria cookies nem salva dados em armazenamento local.

O botão de copiar grava somente o comando escolhido na área de transferência, após seu clique. O simulador de níveis funciona somente nesta página e não altera dados do bot.

A hospedagem pelo GitHub Pages pode processar dados técnicos de acesso conforme suas próprias políticas. Consulte a declaração de privacidade do GitHub.

02 / AO USAR O BOT

Dados processados pelo bot

O bot pode processar identificadores de usuários e grupos, comandos, mensagens e mídias relacionadas às solicitações. Configurações, aceite de termos, progressão de nível, benefícios e registros operacionais podem ser armazenados para manter o serviço.

O tratamento depende dos comandos e recursos utilizados. Conversões, buscas e integrações podem envolver serviços de terceiros. Evite enviar informações sensíveis ou conteúdo de outras pessoas sem autorização.

03 / LINKS EXTERNOS

Serviços externos

Links para WhatsApp, GitHub, Alyka API e Yoshikawa Streaming levam a outros serviços. O uso nesses destinos segue suas próprias condições e práticas de privacidade.

04 / FALE COM O RESPONSÁVEL

Contato

Entre em contato com Yoshikawa Softwares pelo e-mail yoshikawa.softwares@proton.me para obter esclarecimentos ou solicitar acesso, correção ou exclusão de dados associados ao serviço, quando aplicável.

Informe apenas o necessário para identificar a solicitação. Nunca envie senhas, códigos de pareamento ou arquivos de sessão.
